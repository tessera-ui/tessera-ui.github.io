# 多语言与本地化

Tessera 通过 `tessera-i18n` 与 `tessera-build` 接入 [Fluent](https://projectfluent.org/) 消息目录。当前语言由应用入口以响应式状态持有，运行时切换语言会自动重建读取过翻译文本的组件。

## 配置目录与 `.ftl` 文件

在 `Cargo.toml` 中添加 `tessera-i18n`（构建依赖中保留 `tessera-build`），并在 `tessera-config.toml` 中启用 `[i18n]`：

```toml
[i18n]
dir = "locales"
fallback = "en"
```

在指定目录下为每种语言建一个子文件夹，按模块拆分 `.ftl` 文件：

```text
locales/
├── en/
│   ├── notes.ftl
│   └── settings.ftl
└── zh-CN/
    ├── notes.ftl
    └── settings.ftl
```

同一语言目录下的所有 `.ftl` 会合并成一个目录，因此同一语言内消息 ID 不能重复：

```ftl
# locales/en/notes.ftl
notes-title = Notes
notes-greeting = Hello, { $name }
notes-selected = { $count ->
    [one] One note selected
   *[other] { $count } notes selected
}
notes-delete = Delete note
    .description = Moves the note to the trash
```

```ftl
# locales/zh-CN/notes.ftl
notes-title = 笔记
notes-greeting = 你好，{ $name }
notes-selected = 已选择 { $count } 条笔记
notes-delete = 删除笔记
    .description = 将这条笔记移到废纸篓
```

随后在 `EntryPoint` 注册 `res::i18n()`（如需指定初始语言，可链式调用 `.locale(langid!("zh-CN"))`）：

```rust
#[tessera_ui::entry]
pub fn run() -> EntryPoint {
    EntryPoint::new(app::app)
        .config(res::application())
        .package(tessera_components::ComponentsPackage)
        .package(res::i18n())
}
```

## 查找消息与属性

无参消息用 `res::I18N.text(...)`，带变量或复数用 `res::I18N.format(...)`，Fluent 属性写成 `消息ID.属性名`。请在组件构建期间解析文案，这样切换语言时读取该消息的组件会自动重建：

```rust
use tessera_components::{
    column::column,
    icon_button::icon_button,
    material_icons::filled,
    text::text,
};
use tessera_i18n::FluentValue;
use tessera_ui::tessera;

use crate::res;

#[tessera]
fn notes_summary(count: u32) {
    column().children(move || {
        text(res::I18N.text("notes-title"));
        text(res::I18N.format("notes-greeting", [("name", FluentValue::from("Ada"))]));
        text(res::I18N.format("notes-selected", [("count", FluentValue::from(count))]));
        icon_button()
            .icon(filled::DELETE_SVG)
            .accessibility_label(res::I18N.text("notes-delete"))
            .accessibility_description(res::I18N.text("notes-delete.description"))
            .on_click(|| {});
    });
}
```

状态里应保存消息 ID 或原始业务数据，不要保存已经翻译好的字符串。如果某条消息在当前语言和 `fallback` 目录里都找不到（或缺少参数），`text` / `format` 会直接返回消息 ID 本身。

## 运行时切换语言

在动作回调中通过 `I18n::current()`（或不确定是否注册时用 `I18n::try_current()`）读取和切换语言：

```rust
use tessera_i18n::{I18n, langid};

I18n::current().set_locale(langid!("zh-CN"));
```

`I18n::current().locales()` 会列出应用目录支持的所有语言，可直接用来渲染语言选择器。

## 覆盖组件库内置文案

`tessera-components` 内置的控件文本（如文本框右键菜单）使用 `md3-*` 前缀的消息 ID，默认内置 `en` 与 `zh-CN`。应用自己的目录优先级高于组件库，只需在应用 `.ftl` 中定义同名 `md3-*` 条目并保留原参数即可覆盖（完整 ID 列表见 Tessera 仓库 `crates/tessera-components/locales/`）。

## 在测试中验证多语言

在无头测试中启动真实入口，可以同时验证包注册和各语言下的无障碍文本（详见[测试与无头自动化](/zhHans/guide/testing)）：

```rust
use std::time::Duration;

use tessera_i18n::{I18n, langid};
use tessera_ui::{accesskit::Role, headless::HeadlessConfig};

#[test]
fn toolbar_is_translated() {
    let mut renderer = crate::run()
        .into_headless(HeadlessConfig {
            width: 400,
            height: 300,
            scale_factor: 1.0,
            frame_time: Duration::from_millis(16),
            ..Default::default()
        })
        .expect("headless renderer");

    renderer.run(|| I18n::current().set_locale(langid!("zh-CN")));
    renderer.render_frames(2);

    let tree = renderer.inspect_accessibility().expect("accessibility tree");
    assert!(tree.find("删除笔记", Role::Button).is_some());
}
```

注意 Fluent 插值参数两侧会带有不可见的 Unicode 方向隔离符，手动比对插值文本时请使用 `tessera_ui::testing::text_matches` 或 `visible_text`。
