# Localization

Tessera uses [Fluent](https://projectfluent.org/) catalogs via `tessera-i18n` and `tessera-build`. The active locale lives in entry-owned reactive state, so changing the language at runtime rebuilds every component that reads localized messages.

## Setting up catalogs

Add `tessera-i18n` to `[dependencies]` (and keep `tessera-build` in `[build-dependencies]`), then configure `[i18n]` in `tessera-config.toml`:

```toml
[i18n]
dir = "locales"
fallback = "en"
```

Organize `.ftl` files by feature under one folder per language tag:

```text
locales/
├── en/
│   ├── notes.ftl
│   └── settings.ftl
└── zh-CN/
    ├── notes.ftl
    └── settings.ftl
```

All `.ftl` files inside a language directory merge into one catalog for that locale, so keep message IDs unique across files in the same language. Example `locales/en/notes.ftl` and `locales/zh-CN/notes.ftl`:

```ftl
# locales/en/notes.ftl
notes-title = Notes
notes-greeting = Hello, { $name }
notes-selected = { $count ->
    [one] One note selected
   *[other] { $count } notes selected
}
notes-delete = Delete note
    .description = Moves the note to the trash
```

```ftl
# locales/zh-CN/notes.ftl
notes-title = 笔记
notes-greeting = 你好，{ $name }
notes-selected = 已选择 { $count } 条笔记
notes-delete = 删除笔记
    .description = 将这条笔记移到废纸篓
```

Register `res::i18n()` on your `EntryPoint` (optionally setting a custom startup locale with `.locale(langid!("zh-CN"))`):

```rust
#[tessera_ui::entry]
pub fn run() -> EntryPoint {
    EntryPoint::new(app::app)
        .config(res::application())
        .package(tessera_components::ComponentsPackage)
        .package(res::i18n())
}
```

## Looking up messages and attributes

Call `res::I18N.text(...)` for plain messages, `res::I18N.format(...)` for arguments and plurals, and `id.attribute` for Fluent attributes. Resolve strings during component builds so language changes invalidate and rebuild the reading components automatically:

```rust
use tessera_components::{
    column::column,
    icon_button::icon_button,
    material_icons::filled,
    text::text,
};
use tessera_i18n::FluentValue;
use tessera_ui::tessera;

use crate::res;

#[tessera]
fn notes_summary(count: u32) {
    column().children(move || {
        text(res::I18N.text("notes-title"));
        text(res::I18N.format("notes-greeting", [("name", FluentValue::from("Ada"))]));
        text(res::I18N.format("notes-selected", [("count", FluentValue::from(count))]));
        icon_button()
            .icon(filled::DELETE_SVG)
            .accessibility_label(res::I18N.text("notes-delete"))
            .accessibility_description(res::I18N.text("notes-delete.description"))
            .on_click(|| {});
    });
}
```

Store message IDs or raw data in `remember` / `Model` rather than pre-formatted translated strings. If a message or required argument is missing in every catalog (after falling back to the `fallback` locale), `text` and `format` return the message ID itself.

## Switching languages at runtime

Read or update the active entry's locale through `I18n::current()` (or `I18n::try_current()` when localization may not be registered):

```rust
use tessera_i18n::{I18n, langid};

I18n::current().set_locale(langid!("zh-CN"));
```

`I18n::current().locales()` lists all locales available in the application catalog for building a language picker.

## Overriding built-in component strings

Built-in controls in `tessera-components` use `md3-*` message IDs (shipping `en` and `zh-CN` by default). Application catalogs take precedence over library catalogs—to customize a built-in label, define the same `md3-*` ID in your own `locales/` files (keeping the original arguments from `crates/tessera-components/locales/` in the Tessera repository).

## Verifying translations in tests

Run your app's real `EntryPoint` in a headless test to verify both registration and translated accessibility labels across locales (see [Testing and headless automation](/guide/testing)):

```rust
use std::time::Duration;

use tessera_i18n::{I18n, langid};
use tessera_ui::{accesskit::Role, headless::HeadlessConfig};

#[test]
fn toolbar_is_translated() {
    let mut renderer = crate::run()
        .into_headless(HeadlessConfig {
            width: 400,
            height: 300,
            scale_factor: 1.0,
            frame_time: Duration::from_millis(16),
            ..Default::default()
        })
        .expect("headless renderer");

    renderer.run(|| I18n::current().set_locale(langid!("zh-CN")));
    renderer.render_frames(2);

    let tree = renderer.inspect_accessibility().expect("accessibility tree");
    assert!(tree.find("删除笔记", Role::Button).is_some());
}
```

Note that Fluent wraps interpolated arguments with Unicode directional isolates; use `tessera_ui::testing::text_matches` or `visible_text` when comparing interpolated output manually.
